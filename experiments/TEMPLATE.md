# 实验名称

## 研究问题

需要区分的解释是什么，为什么现有观察还不够？

## 实验设计

| 字段 | 记录 |
|---|---|
| 实验编号与状态 | 计划中、运行中、完成、无效或中止 |
| 模型与起点 | 模型、revision、checkpoint、是否完整恢复 |
| 数据与采样 | 训练/验证划分、题数、组大小、长度上限、温度 |
| 对照与比较单位 | 固定输入、固定 batch 或独立在线分支 |
| 优化设置 | 奖励、优势、归一化、学习率、精度、裁剪、更新次数 |
| 重复与预算 | 种子、轮次、token、墙钟时间 |
| 主要指标 | 定义、分母、聚合方式及预设阈值 |

## 结果与证据

链接仓库中的聚合数据、图表和来源摘要。保留关键阴性结果、异常及实际执行与计划的偏离。未完成时只报告已完成部分。

## 判断与下一步

区分观察、干预支持和推测。说明结果改变了哪个判断，以及下一个最小实验如何区分剩余解释。
