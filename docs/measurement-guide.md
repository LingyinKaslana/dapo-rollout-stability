# 指标与证据怎么读

同一条曲线上的数值必须有相同的分母、采样设置和实验身份。这个项目同时包含矩阵重建、固定回答重放、自然生成和在线训练；它们回答的问题不同。

## 五类证据

| 类型 | 可以回答 | 不能直接回答 |
|---|---|---|
| 结构测量或 oracle 拟合 | 已知新旧张量时是否可压缩、可近似 | 在线能否便宜地预测未知新张量 |
| 固定 token 的前向或反向探针 | 相同输入下权重、精度、模块变化的局部效应 | 自然生成发生率、长期训练收益 |
| 固定历史 batch 重放 | 控制输入与起点后，修改损失的短程作用 | 完整在线采样反馈下的结果 |
| 在线训练分支 | 方案与采集器共同作用后的实际轨迹 | 将不同分支每一轮视为相同样本的配对比较 |
| 固定题评测与标注 | 在给定题目和采样设置下的行为与质量 | 全部任务分布、独立训练种子的普遍结论 |

单条轨迹内的题目 bootstrap 不能替代独立训练种子。事后挑出的异常前缀不能当作前瞻预警器，也不能用于估计全体问题的异常率。

## 缓存误差

文中 $E$ 通常指每层 Q/K/V 线性投影的输入，不是仅指词嵌入。K 要区分线性投影、QK-normalization 后和 RoPE 后的实际 cache；Q 不属于持久 KV-cache。

三种误差回答不同问题：

- **相对缓存误差**：$\|\hat K-K_{new}\|/\|K_{new}\|$，衡量相对整个新缓存的偏差。
- **相对增量误差**：$\|\widehat{\Delta K}-\Delta K\|/\|\Delta K\|$，衡量更新本身恢复了多少。
- **函数误差**：后续固定位置的分布 KL、总变差、top-1 一致率或目标 token log-prob 改变。

新旧差很小时，整个缓存的相对误差可以很小，而增量误差仍接近 100%。灰度图的绝对值和各图独立色标也可能放大“有规律”的感觉；带符号误差、统一色标和留出测试需要同时看。采样 512 行得到的谱不是完整序列矩阵的精确秩。

## 轮数和梯度

8B full8 正式设置的一轮包含 64 组 × 8 条回答，分成 **4 次优化器更新**。`actor/grad_norm` 是这四次裁剪前范数的聚合均值，不能当作单次峰值。新续训另存每次更新的原生范数。裁剪阈值为 1，之后才进入 AdamW，所以范数 100 倍不代表实际参数更新大 100 倍。

有些历史报告的 `actor_updates` 实际表示训练轮次提交数。记录完整轮次、actor 已提交、模型已保存、Adam 状态完整是四个不同状态，实验索引分别注明。

## p0、q、p 与 PPL

令 $q_t$ 是 token 当时被生成时的行为策略概率；跨轮回答不同位置可能来自不同策略版本。$p_{0,t}$ 是本轮更新前训练引擎在同一固定 token 上重新计算的概率；$p_{\theta,t}$ 是优化过程中的当前概率。

原 PPO 的比例使用 $p_\theta/p_0$。诊断 $p_0/q$ 揭示的失配并不自动进入原 PPO 损失。它还可能混合策略版本差异与同权重不同引擎的数值差异，必须用控制实验拆开。

单个实际采样 token 的 NLL 为 $-\log p(a)$，概率差为 $|p(a)-q(a)|$，二者不是一个量，也都不等于整个词表分布的距离。原生训练日志中的 PPL 口径是：每条回答按有效 token 求平均 NLL，先取指数，再对回答取算术平均。

$$\operatorname{PPL}_{log}=\frac1N\sum_i\exp\left[-\frac1{T_i}\sum_t\log p(a_{it})\right].$$

这既不同于全部 token 合并的 PPL，也不同于对平均 log-PPL 再取指数。少数回答可支配算术均值；分析尾部时要保留中位数、分位数和贡献占比。单 token 极低概率本身也不足以解释参数梯度爆炸：softmax NLL 对 logits 的梯度有界，参数梯度还经过网络的反向响应。

## 长度、准确率与异常率

训练长度是当轮选入训练的回答长度；固定题验证长度来自另一题目集合和采样温度。8B 正式设置训练为 T=1，验证为 T=0.6；不能混成同一条数据流。

`mean@4` 表示每题四次回答的平均正确率，再按明确的题目权重汇总；它不是至少答对一次的 `pass@4`。首中实验的“100 次内覆盖”来自有限采样，100 次都没答对不意味着真实成功概率为零。

机械重复规则、LLM 的语义循环标签、乱码、离题和虚构对话分别记录。正常的多方法尝试、自我纠错、长证明和一次结尾复核不应直接算循环。LLM 标签保留 uncertain；规则阴性不意味着输出正常，八例盲审也不能用于校正整个语料库的错误率。

## 复现材料的范围

当前仓库保留研究章节、逐项聚合证据、图表、历史训练快照及基于这些聚合数据的重绘工具。权重、逐题原回答和完整训练状态保留在实验存储中。本仓库提供**聚合结果的可复核与图表重绘**，不声称克隆后即可重跑全部训练。后续发布可移植训练代码时，必须连同配置、依赖版本、数据分割与正确恢复协议一起整理。
