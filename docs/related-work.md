# 相关工作与本项目的对应问题

以下是探索过程中直接用到的参照方法与诊断线索。论文的结论属于其原实验设置；本项目的数据不能仅因现象相似就视为该机制的复现。链接与标题核对日期为 2026 年 11 月 4 日。

| 工作 | 与我们的问题有什么关系 | 本项目如何区分 |
|---|---|---|
| [APRIL](https://arxiv.org/abs/2509.18521) | Active Partial Rollouts，针对 RL 长尾生成采用部分 rollout | 我们沿用跨轮 token 续写来研究调度和稳定性；实验中的跨权重前缀会重建 KV，不等于已采用浅层 E/V 近似复用 |
| [DroidSpeak](https://arxiv.org/abs/2411.02820) | 在相同架构模型间选择性重算部分层并复用其余 KV | 我们关注训练中相邻权重，并探索浅层 E/V 与 K 非对称处理；局部近似和在线速度仍须分别验证 |
| [DIVA-GRPO](https://arxiv.org/abs/2603.01106) | 自适应难度变体、局部与全局组优势用于保持有效奖励信号 | 4+4 是对同一题采样与停止规则的修改；没有复现 DIVA 的多模态变体构造，也没有借其理论证明本方案无偏 |
| [ShorterBetter](https://arxiv.org/abs/2504.21370) | 用组内最短正确回答定义采样最优长度，作为奖励信号 | 我们的“超过同组已知正确长度两倍则停止”目前只是离线反事实统计，停止规则与奖励塑形是不同干预 |
| [Beyond Precision](https://arxiv.org/abs/2602.01826) | 将训练推理失配与优化过程联系，提出以长度变化触发学习率下降 | 提醒同时监测长度、梯度与失配；我们的早期长度增长没有同时出现梯度爆炸，不能把长度当成充分预警条件 |
| [STAPO](https://arxiv.org/abs/2602.15620) | 分析少量异常 token 的优化影响并抑制其梯度扰动 | 促使我们查 token 级归因；本项目的选定峰值没有被最高 NLL/概率差尾部的净梯度贡献解释，尚未复现其完整算法 |
| [Lazy Likelihood Displacement](https://arxiv.org/abs/2512.04220) | 在工具搜索 RL 中研究正确和错误回答的似然下降及训练崩溃 | 为负优势与旧回答似然诊断提供方向；纯数学、APRIL 跨轮设置与搜索代理不同，不能直接迁移全部因果结论 |

已实现的实验与建议继续研究的方法，分别在[实验索引](../experiments/README.md)和[问题与决策](questions-and-decisions.md)中标注。项目没有将这些工作的报告数字当作自己的实验结果。
